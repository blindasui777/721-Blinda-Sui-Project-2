# Project 2: Air Quality Analysis

## Project Description
This project processes and explores air quality measurements from Durham County, North Carolina, between 2018 and 2020. The goal is to clean daily pollutant measurements and examine patterns in CO, PM2.5, and O3 concentrations using summary tables and visualizations.

## Data Source
The data were obtained from the EPA air pollution monitor at RDU Airport. Three datasets are included:
- AQ_2018.csv
- AQ_2019.csv
- AQ_2020.csv (January–April only)

## File Structure
- `Sui_Blinda_Project2.Rmd`: R Markdown file containing the cleaning function, data processing, tables, plots, and interpretations.
- `721 Project2 Data/`: Folder containing the three original CSV datasets.
- `README.md`: Project description and reproduction instructions.
- `Sui_Blinda_Project2.docx`: Final Word report generated from R Markdown.

## How to Reproduce
1. Download or clone the GitHub repository.
2. Open the R project in RStudio.
3. Install the required packages: `tidyverse`, `lubridate`, `knitr`, and `rmarkdown`.
4. Open `Sui_Blinda_Project2.Rmd`.
5. Click **Knit** to generate the Word report.
